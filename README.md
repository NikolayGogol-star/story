# История, которой ещё нет

Локальный прототип литературного квеста. Короткое вступление, четыре главы с авторскими текстами и иллюстрациями, три ключа, сохранение прогресса. Опубликован в NikolayGogol-star/story.

## Структура

- `index.html` — страница и доступная разметка.
- `style.css` — оформление и мобильная версия.
- `script.js` — переходы, проверка ключей, сохранение.
- `content.js` — названия, абзацы и иллюстрации.
- `config.js` — ключи и Telegram.
- `assets/` — локальные изображения и текстура бумаги.

## Запуск

Можно открыть `index.html` напрямую. Для надёжного сохранения и проверки условий публикации предпочтителен локальный HTTP-сервер. Из этой папки:

```sh
python3 -m http.server 8000
```

Открой http://localhost:8000. Установка пакетов не нужна.

## Тексты и иллюстрации

В `content.js` замени строки массива `paragraphs` на окончательные абзацы. Каждый абзац — строка в кавычках; кавычки внутри строки нужно экранировать. Текст выводится как обычный текст, а не HTML. Порядок четырёх объектов соответствует главам. Не добавляй кодовые фразы в абзацы, если их не нужно показывать.

Для иллюстрации положи файл в `assets/`, задай `illustration: './assets/chapter-1.jpg'` и описание в `illustrationAlt`. Изображения пока не добавлены: они будут выбраны отдельно.

Основной шрифт — системный Georgia с кириллицей, без внешних запросов. При добавлении другого шрифта положи лицензированный WOFF2 с кириллическими символами в `assets/` и подключи через `@font-face` в CSS.

## Ключи

В `config.js` измени три строки в `KEYS`. Порядок: I → II, II → III, III → IV. Проверка игнорирует регистр, ё/е, внешние и повторяющиеся пробелы, конечные знаки препинания.

Исходные ключи прототипа: «золотой ключик», «красота в глазах смотрящего», «взгляни на главную героиню».

## Telegram

В `config.js` укажи `TELEGRAM_URL: 'https://t.me/ТВОЙ_АККАУНТ'`. Пока строка пустая: кнопка не ведёт к чужому аккаунту. Проверяются ссылки на `https://t.me/`.

## Прогресс

В localStorage сохраняются номер максимальной открытой главы (0–3) и факт завершения: открытие IV главы. При возврате открывается последняя доступная глава. Прогресс привязан к браузеру и адресу сайта. При запрете хранилища квест работает до закрытия страницы. Для повторного теста удали запись `anna-story-progress-v1` в хранилище браузера или открой отдельный профиль. Новое значение `STORAGE_KEY` сбросит прогресс у всех читателей.

## GitHub Pages

1. Создай репозиторий `anna-story`.
2. Загрузи **содержимое этой папки** в корень репозитория, включая `assets/`.
3. В настройках репозитория открой Pages, выбери публикацию из ветки, ветку `main`, папку `/ (root)` и сохрани.
4. После завершения публикации используй выданный GitHub адрес вида `https://USERNAME.github.io/anna-story/`.
5. Проверь путь, окончательные тексты, ключи и Telegram, затем создай QR для этого адреса.

Все ресурсы используют относительные пути. Backend, базы данных, ключи API, аналитика и платные сервисы отсутствуют. На статическом сайте кодовые фразы доступны при просмотре исходного кода; это игровая механика, а не защита секретных данных.

## Пролог и иллюстрированные главы

В `content.js` отдельный объект `STORY_PROLOG` содержит пролог, а `STORY_CONTENT` — четыре главы. Полные авторские тексты внесены дословно. Вставь каждый авторский абзац отдельной строкой, сохраняя пунктуацию. Изображения `assets/chapter-1.png` … `chapter-4.png` подключены без кадрирования. Все иллюстрации расположены перед номером и названием главы; портрет IV главы сохраняет всю композицию. Первая книга открывается на прологе; после него нажми «Начать первую главу».

Для тестирования с начала открой консоль именно на странице сайта и выполни `resetAnnaStory()`. Это сбросит только запись прогресса этого квеста. В интерфейсе читательницы кнопки сброса нет.

Проверка: обложка → пролог → глава I → три ключа из config.js → глава IV. После II главы перезагрузи страницу и проверь восстановление; перечитай предыдущие главы. Проверь фотографии целиком на телефоне и Telegram после заполнения `TELEGRAM_URL`. Telegram настроен на https://t.me/IraBabkina1995.
